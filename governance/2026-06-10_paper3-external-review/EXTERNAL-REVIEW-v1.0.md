Full list, severity-ordered, with the reason each one matters. Scope: Paper 3 v1.0 as released, plus the program-level items that bear on running it.

BLOCKING — fix before any threshold sheet locks

1. D2 mixture gap. The gate tests departure from each pure shortcut prediction. A blend (e.g. 60% operation, 40% recency) departs from every pure null while staying substantially shortcut-driven — and the existing non-claim doesn’t cover it, because a mixture of declared shortcuts isn’t “outside the declared battery.” Why it matters: it changes what a certification means. A certified candidate could carry exactly the contamination Paper 2 spent its whole length mapping. Your own series supplies the counterexample. Fix: dual-mode D2 — Paper 1’s Table D performance floor (exceed max-dummy by margin, which bounds any blend of declared policies) plus pattern departure. Zero runs needed.

MAJOR — fix in v1.1, before or alongside first application

2. No satisfiability demonstration. Seven fail-closed gates, tie-equals-fail, worst-case-across-repeats — and no evidence the conjunction is passable by anything. The one defensive sentence (“a mapped boundary, not an unusable protocol”) is assertion. Why: a gate that can never open is observationally identical to a miscalibrated gate, and you can’t tell which you have. Paper 2 carried a positive control for exactly this reason; Paper 3 has none. Fix: derivation-type arithmetic showing the window is nonempty at realistic N — no candidate, no threshold value, just math.

3. D1×D7 squeeze unquantified. D1 pushes the baseline up; D7 punishes near-ceiling. The window between them shrinks with N — at n=24, deterministic same-item pairing resolves only a ~20-point drop; useful resolution needs n≈96+. Why: a candidate can satisfy D1 and be structurally incapable of passing D7 at any useful MDD, and the protocol never warns the threshold author. minimum_N_rationale is silently carrying the whole load. Fix: same half-page of arithmetic as #2 — they’re one note.

4. Certifier error rates unexamined. The protocol can false-certify (mixtures, out-of-battery shortcuts) and false-reject (margin strictness compounding across a five-policy battery at small N). Nothing states the operating characteristics or what would validate the certifier itself. Why: this is an instrument-qualification protocol that never qualifies itself — the exact gap the series exists to close, one level up. Fix: a gate-provenance table (which gates’ ancestors caught real artifacts) plus the plain statement that no formalized gate has been exercised.

MODERATE — quality items, v1.1

5. Short-circuit evaluation thins the fallback claim. First failure stops review, so a fully-failed candidate yields one data point, not seven. Why: the paper’s own insurance position — “if nothing certifies, we’ve mapped the boundary” — needs full gate vectors to be a map. Fix: pre-registered evaluation_mode: short_circuit | full_profile field.

6. D6 timestamp wording contradicts A.1. D6’s text implies both timestamps are sheet-side; A.1 correctly moved the access timestamp to the evidence bundle. Why: the firewall is the one mechanism that cannot afford ambiguity — it’s the anti-tuning guarantee. One sentence fixes it.

7. Disclaimer repetition got worse. The stress-side non-claim now appears three-plus times in materially identical form. Why: repetition reads as institutional anxiety, not rigor, and buries the paper’s actual ideas (D7, negative-certification-as-result). State each lock once, reference it after.

PROGRAM-LEVEL — not Paper 3 defects, but they bound what it can deliver

8. The gate has never opened on linkage. Only hop2 (single-hop) has ever cleared. Why: “linkage baselines are genuinely hard” and “gate miscalibrated for linkage” are observationally identical until one multi-hop construction passes — a non-identifiability problem about the instrument itself.

9. Zero compression rungs ever run. The entire program is pre-stress. Why: the instrument has never taken a measurement under the condition it was built for; even after certification, the first stress sweep is a first-light event with its own unknowns (stress-side shortcut substitution, which D2 explicitly does not certify against).

10. Single-author, single-team, no external validation. Why: every check so far is self-applied. The discipline is real, but adversarial review by people with no stake is the test it hasn’t faced — and the service ambition makes that test mandatory, not optional.

11. Governance gap on deferred majors. Some v0.7 referee items were deliberately deferred or rejected between v0.7 and v1.0, and I can’t find the decision on the ledger. Why: in a program whose entire ethic is documented decisions, a silent deferral is itself a finding. If it’s recorded, point me to it and this one closes.

The pattern, in one line: items 1–4 are all the same concern wearing different clothes — the certifier itself is the one instrument in the program that hasn’t been put through the program’s own discipline.
