# Survival Is Not Correctness

**A Staged, Fail-Closed Metrology Protocol for Stress-Retention Evaluation**
*Lessons from a blocked seam-under-quantization test*

E. A. Flores · Apiana AI, Inc.

A staged, fail-closed protocol for interpreting **stress-retention** results in language models — for
deciding when "X% of behavior survived compression" actually means *retained capability* rather than
*retained error*. The protocol gates a compression-stress sweep behind an explicit reference-precision
(FP16) feasibility check, scores generated output on three separable axes (scaffold, format, content),
and reports correctness as a three-part contract (baseline correctness, stressed correctness, same-error
identity) instead of a single retention number.

The instrument was developed when a seam-directed stress test (does low-bit quantization tear multi-hop
composition?) repeatedly failed its reference baseline. The paper reports **two distinct result
families** — earlier chain-task runs that completed FP16/INT8/INT4 sweeps, and a purpose-built
seam-directed line (Exp6–Exp8B) that was blocked at FP16 only — and **makes no claim that a compositional
seam exists** or that the full instrument has produced a clean seam measurement.

## Rebuilding the PDF

The rendered PDF is included. To rebuild from the Markdown + figures:

```bash
python -m pip install markdown
# install wkhtmltopdf (https://wkhtmltopdf.org/) and ensure it is on PATH
python tools/build_pdf.py
```

This regenerates `survival-is-not-correctness.pdf`. The figures are shipped as final PNGs and are not
regenerated by this script.

## Claims and scope

A metrology / measurement-protocol paper. It deliberately does **not** claim a compositional seam exists
or does not exist; does not claim INT8/INT4 causes or prevents compositional failure; infers no mechanisms
from behavioral outputs; makes no general quantization-robustness claim; and does not generalize beyond
the tested constructions, models, tokenizers, and decoding settings. Same-error identity is **specified
and operationalized**, not established as having adjudicated a compression-retention result. The validated
components of the instrument are ready to reuse; the full instrument has not produced a clean seam
measurement.

## Reproducibility and provenance

Reproducibility is uneven across runs, and the gaps are **documented rather than smoothed** (manuscript
§5.1, Appendix A, and `artifact-bundle-index.md`). Exp6, Exp7, and pre-amendment Exp8A are **not**
presented as fully reproducible. The run-artifact **files** (raw output packets, manifests, task/scorer
source, run logs) are not derivable from the manuscript and are not included here; they belong at the
reserved paths `artifacts/`, `src/`, and `logs/` per `artifact-bundle-index.md` §D.
